## 페이지 구성

탭으로 나누지 않고 한 페이지에 이어서 보여줍니다. 비슷한 분야 2개를 **묶음** 하나로 모아, 컨트롤 타워와 묶음 3개가 각각 한 화면을 차지합니다(총 4화면). 스크롤하면 다음 화면에 딱 맞춰 넘어가서(스크롤 스냅) 다른 요소가 화면에 걸치지 않습니다. 밝은 배경에 분야별 파스텔 색이 번지는 카드와 흰색 알약 버튼을 쓰는 디자인입니다.

| 화면 | 묶음 | 분야 |
| --- | --- | --- |
| 1 | 컨트롤 타워 | — |
| 2 | 디자인 & 개발 | 웹/UI/UX 디자인, 바이브 코딩 |
| 3 | 업무 & 글쓰기 | 워크플로우 자동화, LLM / 글쓰기 |
| 4 | 콘텐츠 & 발표 | AI 아바타·영상, 시각화 & 프레젠테이션 |

```
┌───────────────┬──────────────────────────────────────────┐
│ 컨트롤 타워    │              디자인 & 개발                 │
│               │  ┌──────────────────┐ ┌──────────────────┐ │
│ 디자인 & 개발  │  │ 01 웹/UI/UX 디자인│ │ 02 바이브 코딩     │ │
│  ● 웹/UI/UX   │  │ (Figma 무료 플랜 >)│ │ (Lovable 무료 플랜>)│ │
│  ● 바이브 코딩 │  │ (V0    무료 플랜 >)│ │ (Cursor  무료 플랜>)│ │
│ 업무 & 글쓰기  │  │ ...               │ │ ...               │ │
│  ● ...        │  └──────────────────┘ └──────────────────┘ │
└───────────────┴──────────────────────────────────────────┘
                     (알약을 누르면 세부 내용 창이 뜸)
```

### 1. 좌측 사이드바
- 맨 위에 **컨트롤 타워**, 그 아래 묶음 3개와 각 묶음의 분야 2개 (분야 색 점 표시)
- 묶음을 누르면 그 화면으로 스크롤, 분야를 누르면 그 화면으로 스크롤한 뒤 해당 분야 카드를 잠깐 강조
- 스크롤하면 지금 보고 있는 묶음이 사이드바에 강조 표시됨

### 2. 컨트롤 타워 (첫 화면)
- 가운데 정렬 제목, 분야 수와 AI 수
- 묶음별 세로 3줄에 분야 카드 6개: 카드를 누르면 해당 분야로, 카드 안 아이콘을 누르면 그 AI 창을 연 채로 이동

### 3. 묶음 화면
- 가운데 정렬된 묶음 이름과 소개, 아래에 분야 카드 2개를 나란히 배치
- 분야 카드: 번호, 분야 이름, 소개, AI마다 흰색 알약 버튼 (아이콘, 이름, 요금 구분 배지, `>`)
- 요금 구분 배지는 누르지 않아도 보임: `무료` · `무료 플랜 있음` · `무료 체험` · `유료`

### 4. 세부 내용 창
- 알약을 누르면 화면 가운데에 창이 뜸 (카드 높이가 늘어나지 않아 한 화면 구성이 유지됨)
- 닫기: ✕ 버튼, 창 바깥 클릭, Esc 키
- 내용: 이름·요금 배지·한줄소개, 장점 / 아쉬운 점, 직접 써 본 소감, 사용 방법 / 사용 요금, 공식 사이트(또는 체험 결과) 버튼
- 내용이 길면 창 안에서만 스크롤됨

### 링크 공유
- `index.html#/build` 처럼 열면 묶음 화면으로, `index.html#/vibe` 처럼 열면 그 분야가 있는 화면으로(카드 강조), `index.html#/vibe/cursor` 처럼 열면 Cursor 세부 내용 창을 연 채로 이동

### 모바일
- 사이드바는 상단 메뉴 버튼으로 접고 펼침
- 묶음 화면의 분야 카드 2개와 컨트롤 타워 카드는 세로로 쌓이고, 스냅 없이 자연스럽게 스크롤
- 세부 내용 창은 화면 아래에서 올라오는 시트로 표시
- 세로가 낮은 데스크톱 화면(700px 미만)에서는 스냅을 끄고 자연스럽게 스크롤

## 보는 방법

`index.html`을 브라우저에서 열면 됩니다. 별도 설치나 서버가 필요 없습니다.
시스템이 다크 모드면 페이지도 어두운 색으로 표시됩니다.

## 내용 수정하기

1. `AI_워크플로우.xlsx`를 고치고 저장합니다.
2. 프로젝트 폴더에서 아래 명령을 실행해 `js/data.js`를 다시 만듭니다.
   ```
   python scripts/build_data.py
   ```
3. 브라우저를 새로고침합니다.

새 AI를 추가했다면 `icons/`에 아이콘을 넣고, `scripts/build_data.py`의 `ICONS`에 이름과 파일명을, `PLANS`에 요금 구분을 적어 주세요.
새 분야를 추가했다면 같은 파일의 `CATS`에 분야 id, 이름, 소개 문구를 적고, `GROUPS`에서 어느 묶음에 넣을지 정해 주세요.

## 변환할 때 자동으로 처리되는 것

- 엑셀 15행(DeeVid AI) 한줄소개의 오타 `드을` → `등을` (엑셀 원문은 그대로)
- 엑셀에서 `\`로 저장된 원화 기호 → `₩`
- 써본 사람(작성자) 열은 데이터에 넣지 않음
- 요금 구분 배지는 엑셀 문장에서 자동으로 판별하지 않고, `build_data.py`의 `PLANS`에 AI별로 직접 지정
- 엑셀 요금 칸에 빠진 무료 플랜(시각화 분야 Claude, Gamma)은 `EXTRA_PRICING`으로 요금 목록 맨 앞에 덧붙임
- 줄 앞의 `` `- ``, `•`, `-` 기호 제거 후 목록으로 표시, `1.` `1)` 형태 단계는 번호 목록으로 표시
- 요금 칸의 `확인일`과 출처 URL은 요금 목록 아래에 작게 표시
- `Lovable (러버블)`처럼 괄호 속 한글 이름은 영문 이름 옆에 작게 표시
- 시각화 & 프레젠테이션의 URL은 체험 결과 공유 링크라서 버튼 이름을 `체험 결과 보기`로 표시
- Claude는 두 분야(LLM, 시각화 & 프레젠테이션)에 같은 아이콘으로 나오고, 내용은 분야별로 따로 표시
